# Simulador de Home Equity — Datalab Global

Simulador estático de Home Equity (crédito com imóvel em garantia): parcela e custo total estimados, Raio-X da decisão e comparação de custo mensal entre tipos de crédito.

- Gerar o site: `python gerador_homeequity.py` (saída em `paginas_seo/`)
- Testes: `python -m pytest -q`
- Regras e estado do projeto: [CLAUDE.md](CLAUDE.md)
